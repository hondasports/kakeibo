# ブランド画像

画面では、拡大しても輪郭が滑らかなSVGを使用します。

| ファイル | 用途 |
| --- | --- |
| `public/suzumemo-logo-lockup.svg` | スズメ・メモ帳・英字・日本語を組み合わせたロゴ |
| `public/suzumemo-app-icon.svg` | 角丸背景付きのアプリアイコン、ファビコン |
| `public/animations/suzumemo-loading/*.svg` | 読み込み中の文字と葉のアニメーション |

文字はフォントに依存しないアウトラインです。既存の字形をもとに輪郭を曲線化し、スズメとメモ帳はベジェ曲線とグラデーションで描き直しています。元画像の細かな紙の質感は再現せず、色とモチーフを引き継いでいます。

読み込み用の各レイヤーは共通の `600 × 161` の座標系を維持しています。文字の位置を変更する場合は、`SuzumemoLoadingLogo.tsx` の文字ごとの切り抜き位置と `lottie.json` のマスクも確認してください。合成版の `logo.svg` は各レイヤーを内包しており、単独で表示できます。

既存のPNGは元データとして残しています。SVGにはラスター画像や外部フォント・外部画像への参照を含めません。
