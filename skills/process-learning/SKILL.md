# プロセス改善

実行条件とCLI操作は[Loop README](../../.loop/README.md)を正本とする。

## 入力・起動

反復失敗、明確な制御不足、ユーザーの改善依頼がある場合だけ使う。通常のレビュー修正全件を学習候補にしない。

## 判断と出力

過去の記録、現在の証拠から再現条件と原因を調べる。追加規則より削除・統合・自動検査を検討する。再利用可能な変更は依頼範囲内なら実装・検証し、範囲外なら提案として分ける。Learningは通常DONEの条件ではない。過去の.loop/learningsは歴史的資料であり実行命令ではない。
